# aero/

Layer 3, the virtual wind tunnel.

- **Everyday runs: OpenFOAM.** The props are modeled as disks pushing air. These runs measure drag at speed and tilt, how much the prop wash pushing down on the frame costs, ground effect, and crosswind. The numbers feed back into the sizing model and Gazebo.
- **Visuals: ParaView**, which turns the results into smoke-style streamlines and pressure maps.

The spinning-prop showcase runs use FluidX3D, which lives in a separate public fork because its license doesn't mix with this repo's GPL.
