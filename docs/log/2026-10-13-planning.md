# 2026-10-13: Planning the drone

**Machine:** laptop

## What happened

First planning session. I went from "I want to build a drone from scratch" to a full plan.

## Key decisions

- **From scratch, my way:** my own flight firmware on parts I can order (no custom PCB). Starting from open-source code is fine.
- **The goal:** a fairly big, fast drone with a camera and GPS, built in stages: get it flying, then add the camera, then GPS.
- **Long flights over a quadplane:** I looked at a VTOL quadplane (a drone with a wing) and dropped it as too complex. Instead it's a long-range quad on 8–10" props with a Li-ion pack, aiming for roughly 25–40 minutes.
- **Smart landing is core:** land now, return to start, land where I click, or go to the nearest safe spot found from a 3D map.
- **Safety first:** a parachute, fired by an independent monitor (my spare Teensy 4.1) so it still works if my firmware crashes.
- **An LLM, but on the laptop:** it turns plain-English commands into flight plans. It never touches the motors; every plan is checked and approved first.
- **Flight controller:** a Nucleo-H743 dev board for bench work, plus an off-the-shelf H743 flight controller board for flying. Same chip, same firmware.
- **Simulate before buying:** four layers (sizing model, CAD, Gazebo + PX4, then my own firmware), iterating on parts until the specs are met. Pricing comes last.

## Ideas that didn't make the cut (for now)

Tilt-rotor flight, thermal vision, the quadplane, toroidal props, a charging dock, a sniffer drone, and more. They're all logged in [decisions.md](../decisions.md).
